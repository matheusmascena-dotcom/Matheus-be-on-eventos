Conectar Instagram via Meta

A conexão usa a API oficial da Meta. O token é enviado diretamente ao Supabase por HTTPS e guardado apenas em armazenamento restrito do servidor; ele não é salvo no navegador, no GitHub ou exibido novamente.

Você não precisa entrar na conta @beonentertainment. Use um token de usuário Meta de uma conta profissional que você administra e que esteja vinculada a uma Página do Facebook. Permissões usuais: pages_show_list, instagram_basic e pages_read_engagement. A Meta precisa permitir Business Discovery para o perfil de destino. Documentação oficial da API Instagram da Meta ↗
